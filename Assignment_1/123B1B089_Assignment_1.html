HTML Tags Reference

Document Structure & Metadata

Tag Description Example
<html> Root element of an HTML document <html>...</html>
<head> Container for metadata <head><title>Page</title></head>
<body> Contains the visible page content <body>Content here</body>
<!DOCTYPE> Document type declaration <!DOCTYPE html>
<title> Document title (shown in browser tab) <title>My Page</title>
<meta> Provides metadata about the document <meta charset="UTF-8">
<link> Links external resources (CSS, icons) <link rel="stylesheet" href="style.css">
<style> Contains CSS style information <style>body { color: red; }</style>
<base> Specifies base URL for relative URLs <base href="https://example.com/">

Text Formatting

Tag Description Example
<p> Paragraph of text <p>This is a paragraph.</p>
<h1> - <h6> Heading elements (h1 to h6) <h1>Main Heading</h1>
<b> Bold text (stylistic) This is <b>bold</b> text.
<strong> Important text (semantic) This is <strong>important</strong>.
<i> Italic text (stylistic) This is <i>italic</i> text.
<em> Emphasized text (semantic) This is <em>emphasized</em> text.
<u> Underlined text This is <u>underlined</u> text.
<mark> Highlighted text This is <mark>highlighted</mark> text.
<small> Small print <small>Copyright notice</small>
<sub> Subscript text H<sub>2</sub>O
<sup> Superscript text x<sup>2</sup>
<code> Inline code fragment Use <code>console.log()</code> to debug.
<br> Line break Line 1<br>Line 2
<hr> Thematic break (horizontal rule) <hr>
<pre> Preformatted text <pre>Text with spaces</pre>

Links & Navigation

Tag Description Example
<a> Hyperlink (anchor) <a href="https://example.com">Link</a>
<nav> Contains navigation links <nav><a href="/">Home</a></nav>

Lists

Tag Description Example
<ul> Unordered list <ul><li>Item 1</li></ul>
<ol> Ordered list <ol><li>First</li></ol>
<li> List item <li>List item content</li>
<dl> Description list <dl><dt>Term</dt><dd>Definition</dd></dl>
<dt> Term in description list <dt>HTML</dt>
<dd> Description in description list <dd>HyperText Markup Language</dd>

Tables

Tag Description Example
<table> Table container <table>...</table>
<tr> Table row <tr><td>Cell</td></tr>
<td> Table data cell <td>Table data</td>
<th> Table header cell <th>Column Header</th>
<thead> Table header section <thead><tr><th>Header</th></tr></thead>
<tbody> Table body section <tbody><tr><td>Data</td></tr></tbody>
<tfoot> Table footer section <tfoot><tr><td>Total</td></tr></tfoot>
<caption> Table title/caption <caption>Monthly Sales</caption>

Forms

Tag Description Example
<form> Container for form elements <form action="/submit" method="post"></form>
<input> Form input control <input type="text" name="username">
<textarea> Multi-line text input <textarea rows="4" cols="50"></textarea>
<button> Clickable button <button type="submit">Submit</button>
<select> Drop-down list <select><option>Choice 1</option></select>
<option> Option in a select <option value="1">Option 1</option>
<label> Caption for a form control <label for="name">Name:</label>

Media

Tag Description Example
<img> Image <img src="image.jpg" alt="Description">
<audio> Audio content <audio controls src="audio.mp3"></audio>
<video> Video content <video controls src="video.mp4"></video>
<iframe> Inline frame <iframe src="https://example.com"></iframe>

Semantic HTML5

Tag Description Example
<header> Introductory content <header><h1>Site Title</h1></header>
<footer> Footer content <footer>Copyright 2024</footer>
<article> Self-contained composition <article><h2>Blog Post</h2></article>
<section> Thematic grouping of content <section><h2>Chapter 1</h2></section>
<aside> Tangentially related content <aside>Related links...</aside>
<main> Main content area <main><article>...</article></main>

Containers

Tag Description Example
<div> Generic block container <div class="container">Content</div>
<span> Generic inline container <span style="color:red">Red text</span>
